# BITFA Signal Bot

ربات تحلیل و امتیازدهی ارزهای معرفی‌شده در کانال BITFA.

## هدف
گرفتن تیکر از واچ‌لیست BITFA → عبور از فیلترها → امتیاز از ۱۰۰ + پیشنهاد ورود/خروج تقریبی.

## وضعیت فعلی
نسخه اولیه - ماژول امتیازدهی در حال ساخت.

## نکات مهم
- کلیدها را هرگز در کد commit نکنید. از Environment Variables استفاده کنید.
- این ربات توصیه مالی نیست (NFA | DYOR).
